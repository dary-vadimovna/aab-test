# Анализ поведения пользователей и результатов A/A/B-теста

## О проекте
Исследование поведения пользователей мобильного приложения по продаже продуктов питания и оценка результатов A/A/B-эксперимента.

В рамках эксперимента пользователи были разделены на три группы:
- **246** — контрольная группа;
- **247** — контрольная группа;
- **248** — экспериментальная группа с изменённым шрифтом.

**Цель исследования:** оценить поведение пользователей мобильного приложения и определить, повлияло ли изменение шрифта на прохождение пользователями воронки и успешную оплату.

## Задачи
- проверить качество и полноту данных;
- определить период, пригодный для анализа;
- построить воронку пользовательских событий;
- рассчитать воронку с помощью SQL;
- провести A/A-тест между контрольными группами;
- провести A/B-тесты и сравнить экспериментальную группу с контрольными группами;
- сформулировать продуктовые выводы и рекомендации.

## Данные и подготовка
Исходные данные содержат:
- 244 126 событий;
- 7 551 уникального пользователя;
- период наблюдений — 25 июля — 7 августа 2019 года.

В ходе подготовки данных:
- проверены пропуски;
- удалены 413 полных дубликатов;
- преобразованы данные о дате и времени событий;
- исключены данные до 1 августа из-за значительно меньшей полноты данных;
- проверено распределение пользователей между экспериментальными группами;
- проверено отсутствие пересечений пользователей между группами.

Для основного анализа использован период **1–7 августа 2019 года**.

Итоговый датасет содержит:
- 240 887 событий;
- 7 534 уникальных пользователя.

Пользователи распределены между группами примерно поровну:
- 246 — 32,97%;
- 247 — 33,36%;
- 248 — 33,67%.

## Воронка событий
Событие Tutorial исключено из воронки как необязательный этап.
Последовательность событий:
`MainScreenAppear → OffersScreenAppear → CartScreenAppear → PaymentScreenSuccessful`

По результатам анализа:
- 47% уникальных пользователей совершили успешную оплату;
- основная потеря пользователей происходит при переходе с главного экрана к каталогу — конверсия составляет 61,91%;
- из каталога в корзину переходят 81,30% пользователей;
- из корзины к успешной оплате — 94,78%.

Воронка также рассчитана с помощью SQL-запроса в SQLite.

## A/A/B-тест
Для сравнения долей пользователей использован **z-тест**, уровень значимости — **α = 0,05**.

Проведены сравнения:
- 246 vs 247;
- 246 vs 248;
- 247 vs 248;
- 246+247 vs 248.

Во всех проведённых сравнениях получены значения **p-value > 0,05**.

Статистически значимых различий между контрольными группами 246 и 247 по этапам воронки не выявлено. Результаты A/A-проверки не дают оснований сомневаться в корректности разбиения пользователей на контрольные группы.

При сравнении экспериментальной группы 248 с контрольной группой 246, контрольной группой 247 и объединённой контрольной группой статистически значимых различий в долях пользователей на этапах воронки также не выявлено.

## Основной вывод
Статистически значимого влияния изменения шрифта на прохождение пользователями воронки не выявлено.
Результаты эксперимента не показывают статистически значимого ухудшения конверсии после изменения шрифта. При этом статистически значимого роста конверсии также не обнаружено.

## Рекомендации
**Изучить переход от главного экрана к каталогу.**
На этом этапе происходит наибольшая потеря: около **38% пользователей** не доходят до каталога. На следующих этапах воронки конверсия значительно выше.

**Проверить всплеск событий 2 августа.**
В экспериментальной группе 248 наблюдается рост количества событий `Cart` и `Payment` без сопоставимого роста числа уникальных пользователей. Стоит дополнительно проверить возможные технические причины этого всплеска.
